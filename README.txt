CarLog Ver.0.87 β

今回の変更:
- 車両情報のオイル交換項目を拡張
  - オイル交換走行距離
  - オイル交換日
  - オイル交換周期
- 初回セットアップにもオイル交換走行距離・日付を追加
- 車両編集画面にもオイル交換走行距離・日付を追加
- ホームの車両情報にもオイル交換距離・日付を表示
- ホームの車両画像エリアで「総走行距離」の下に「オイル交換 ○○ km」を表示
- 整備・維持で登録した「オイル交換」がある場合は、その最新記録を優先して表示
- 整備記録がない場合は車両情報に手入力したオイル交換距離・日付を使用
- 次回オイル交換距離の計算にも最新のオイル交換距離を使用

変更前バックアップ:
- CarLog Ver.0.86 を別ZIPとして保存

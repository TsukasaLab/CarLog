CarLog Ver.0.72 β

今回まとめて反映:
- 維持費・分析: 月別合計カードを4つの主要カードの下へ移動
- 月別バーを押すと選択月の合計を表示
- 整備・維持を分類別に年間/月間集計、分類ボタンで月別バーを切替
- その他支出を分類別に年間/月間集計、分類ボタンで月別バーを切替
- 分類ボタンは横一列
- ホームの今月合計が0円の場合も「0 円」と表示
- 車両管理ボタンを復旧
- 設定の「車両の追加・切替・編集」も車両管理へ遷移
- 設定内の重複した「使い方」ボタンを1つ削除
- ブラウザの戻る/進むでCarLog内のページ履歴を移動
- 車両管理に「更新・期限管理」を追加
- 今回の日付、更新周期、次回の日付、金額、メモを登録
- 毎月/毎年は次回日を自動計算
- ホームに「今回 / 次回」と期限までの日数を表示
- PC版・スマホ版とも共通更新

CarLog Ver.0.92 β

維持費・分析の追加変更:
- 「整備・維持」も「その他支出」と同じように内訳を表示
- 年間の整備・維持内訳:
  - オイル交換
  - フィルター交換
  - 洗車
  - タイヤ交換
  - バッテリー交換
  - 車検
  - 点検
  - 修理
  - その他
  - 既存データに独自分類があれば自動追加
- 月間にも同じ整備・維持内訳を表示
- 整備内訳の各表示欄も、その項目のバーグラフ切替に対応
- 総計を選択したバーグラフは積み上げ式へ変更
  - ガソリン
  - 整備・維持
  - その他支出
  を3色で1本のバー内に表示
- 年間総計:
  - 1月～12月を積み上げバー表示
- 月間総計:
  - 1日～月末を積み上げバー表示
- グラフ上に色分け凡例を追加し、各期間の支出配分を確認可能
- 総計以外の項目を選んだ場合は従来の単色バー表示

変更前バックアップ:
- CarLog Ver.0.91 を別ZIPとして保存

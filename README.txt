CarLog Ver.0.90 β

維持費・分析画面を新仕様へ再構成:
- 上から「年選択 → 年間合計 → 年間の各種合計 → 月選択 → 月合計 → 月の各種合計 → バーグラフ」の順に整理
- 合計表示を切り替える専用ボタンは廃止
- 年間・月間の各表示カード自体をバーグラフの切替ボタンとして使用
- 年間の表示カードを押した場合:
  - 1月～12月の月別バーグラフ
- 月間の表示カードを押した場合:
  - 選択月の1日～月末までの日別バーグラフ
- 年間/月間ともに以下を表示
  - 全体合計
  - ガソリン
  - 整備・維持
  - その他支出
- その他支出はさらに内訳を表示
  - 自動車税
  - 任意保険
  - 駐車場
  - 高速・有料道路
  - 用品
  - その他
  - 既存データに別分類があれば自動追加
- その他支出の内訳は、左インデント・矢印・薄背景で「その他支出の内訳」と分かるデザイン
- その他支出の各内訳カードもグラフ切替に対応
- 日別グラフは項目数が多いため横スクロール対応
- ホームの今月カードから分析を開いた場合は、現在月の日別グラフを対象項目で開く

変更前バックアップ:
- CarLog Ver.0.89 を別ZIPとして保存

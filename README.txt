CarLog Ver.0.84 β

今回の変更:
- スマホホームの「CarLog」とバージョン表示を濃色化して視認性を改善
- ホーム右上の☰を、他画面のメニューボタンと同じ濃紺・角丸デザインへ統一
- ホームの「今月の合計」が0円のとき白文字化して消えていた問題を修正
- 費用区分の上位表示名を「整備・維持」「その他支出」に統一
- 月別合計の内訳をスマホでは項目ごとに改行
- 内訳の項目名と金額の間に1文字分の余白を追加
- 整備・維持のグラフ切替ボタンを全分類表示
- その他支出のグラフ切替ボタンを全分類表示
- 分類ボタン列を横スクロール対応
- 既存データに標準外の分類がある場合も、その分類ボタンを追加表示

変更前バックアップ:
- CarLog Ver.0.83 を別ZIPとして保存

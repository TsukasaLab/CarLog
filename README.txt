CarLog Ver.0.91 β

維持費・分析の表示調整:
- 画面を開くたびに当日の年・月を初期値として使用
- 前回開いていた年・月・グラフ条件は記憶しない
- メニューから開いた場合は「今月の全体合計（日別）」を初期グラフとして表示
- ホームのガソリン等から開いた場合も当日の年・月を使用し、対象項目だけ引き継ぐ
- 月選択欄から年表示を削除し、「10月」のように月だけを表示
- 年選択で選んだ年を基準に、月選択では1～12月だけ変更
- 月選択の左右ボタンは1月/12月の端でも消えず、無効状態が分かる表示に変更
- 年/月の切替ボタンを固定サイズ化し、表示崩れを抑制
- 年間/月間の表示カードを低く・コンパクト化
- ガソリン / 整備・維持 / その他支出をスマホでも横3列表示
- その他支出の内訳も3列を基本として省スペース化
- セクション間の余白、カード内余白、グラフ前余白を縮小

変更前バックアップ:
- CarLog Ver.0.90 を別ZIPとして保存
